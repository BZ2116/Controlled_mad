# RQ1 实验设计与解释

本页描述核心三轮协议；当前完整测量、材料核查、抽样、退化统计与补充对照以[研究规范v2](study-protocol-v2.md)为准。

研究问题是表达改写对判断的影响，是否会因后续同伴互动而变化。当前完整矩阵是三名同模型代理、一次重复、三轮修订；AVeriTeC 的原生四标签保留，金标只参与分析，不进入模型提示。运行时不额外检索网页。

## 一题的流程

1. 三人分别只看题目和证据，产出独立初答 S0。冻结这三份标签与评论，依据数据集、题号、seed=42 选择一个发送者，不按金标、正确性或少数派身份选人。
2. O 是发送者原始 S0 评论。生成三种修辞改写：ethos、logos、pathos；另用精确原文块重排生成 conclusion_front、conclusion_back、support_first、limitation_first。只改变该发送者的评论，冻结标签与其他两人的初答。
3. 七份材料经过严格机械检查和模型语义审核。新增数字/URL、标签变化、审核 fail/uncertain 等会阻止入组。通过审核不等于已证明语义等价；仍应人工抽检。改写同时替换接收者看到的副本和发送者自己的初始历史。
4. 每种材料（O 或某个 R）先共同进入 T1：每人看到另外两人的 S0 评论，再修订判断。此时尚未分叉提示，I/M 共享同一份 T1 结果。
5. T2/T3 分叉：I 继续基于自己的累计历史修订，不接收新的同伴输出；M 接收上一轮另外两人的新输出，保留累计历史。两个分支都固定到 T3，意见一致也不提前停。同一轮后调用的人不会看到本轮先调用者的回复。
6. 每格三票多数裁决；三种不同标签记 `no_majority`。无多数是有效结果，与缺回复/不合格材料等运行缺失分开。

| 材料 | I：首次接触后停止同伴更新 | M：继续同伴更新 |
| --- | --- | --- |
| 原文 O | I-O-T3 | M-O-T3 |
| ethos / logos / pathos | 每操作一个 I-R-T3 | 每操作一个 M-R-T3 |
| conclusion_front / conclusion_back | 每操作一个 I-R-T3 | 每操作一个 M-R-T3 |
| support_first / limitation_first | 每操作一个 I-R-T3 | 每操作一个 M-R-T3 |

共 8×2=16 个终局格。S0、T1、T2 过程记录另存。每种材料实际讨论调用 15 次：共享 T1 三次，加 I/M 各自 T2/T3 共十二次；全题讨论 120 次。通常另有 3 次 S0、3 次修辞生成、7 次审核，共 133 次。16 格不等于 16 次模型请求。

## 主估计量

同题、同一初态、同操作，逐标签计算：

`D = (M-R − M-O) − (I-R − I-O)`

- vote 层：某标签获得的票数 / 3。
- verdict 层：某标签是否获得多数；无多数另有分量。
- 准确率、O→R 裁决翻转、S0→终局改判及正确↔错误是另外的后果指标，不把准确率差等同于类别向量 D。

T1 的 D 因共享快照必为 0；核心是在相同 T2/T3 比较 I/M。多个改写共享同题 O 轨迹，不是七次独立基线。完整 500 题是 3,500 个逻辑配对，但独立题目单位仍是 500，不能把同题的三个代理、七个操作或轮次当成独立样本。

完整矩阵报告每格状态；主轨迹使用各轮四格齐全的配对，缺失分母明确报告。配置 `inference` 后，在题目层重采样完整标签向量、先平均题内重复；终局 verdict 向量整体检验使用 Holm 校正。区间是逐标签点态区间，非同时区间；不是准确率 D 的显著性检验。分析条件于已经冻结的 S0 和改写，不能覆盖所有生成材料与运行随机性。

## 这项设计能回答什么

它能比较受控表达改变在首次接触后的作用，与继续同伴更新之后的作用，观察后续互动对该差异的改变。它不要求出现准确率提升，零效应、负效应和标签漂移均可分析。

三名代理使用同一模型及相同协议，不代表异质的独立专家。temperature=0、没有服务端 seed 时也不能承诺严格确定性。单次运行没有估计重复运行噪声；O/O 诊断和重复运行需要另立设计。出现 D≠0 本身不能证明具体心理机制或纯语义等价。

2026-10-28 的真实三题验收均为初答 3:0 一致，所有终局在表达版本与 I/M 间相同。它验证了接口、材料、共享 T1、消息路由与48格完整度，不能用于推断总体有无效应，尤其没有检验分歧题上的行为。
