# 持续同伴互动与表达效应：实验设计 v2

2026-10-28。显式配置 `study_protocol: continued_peer_exchange_v2`。这是当前实施规范，不代表已完成正式预注册、人工核查或新的真实全量实验。既往探索性运行参与了设计完善，应如实披露；“本次运行前固定”不等于研究者从未见过该数据。

探索性目标不要求预先承诺效应方向，也不应把所有分析包装为确证性。固定关键规则是为了避免边看结果边改口径。模型和数据集确定后，可用[研究记录表](research-record.md)公开区分运行前规则与事后探索。

## 研究问题与识别范围

主问题：在两组已经完成相同首次接触之后，相比独立后续修订，持续同伴更新是否、以及在什么条件下改变表达形式对判断的影响？

对每个标签，令 `Eᵖₜ = Y(P,R,t) − Y(P,O,t)`，`Dₜ = Eᴹₜ − Eᴵₜ`。Y 分别为三票票额和多数裁决指示向量。主结局是 T3 verdict 类别向量 D；准确率、改判、无多数和过程变化为辅助结局。不能以准确率提升与否判断实验是否成功。

共同 T1 的含义是 I-O 与 M-O 共享、I-R 与 M-R 共享，O 与 R 不必相同。D₁ 为构造零，不是实证发现；E₁ 可以非零。T1 的额外修订同时包含阅读与推理，当前设计没有单独识别“第一次看到同伴”相对于等计算量不看同伴的因果效应。

D 是持续同伴更新这一干预包对表达效应的调节/交互，不是中介效应或传播路径证明。M 的消息和上下文多于 I，因此“等轮次”不等于严格等 token 预算。保留这一差别以匹配所研究的持续更新干预，另报实际调用和用量。R 同时替换发送者自身历史和接收者看到的初始评论，结论限定于这一处理。

预期结果没有预设方向：放大、衰减、反转、保持不变均可报告。不同题目的正负变化可能相抵；均值接近零不能自动解释为每题均无影响。

## 主实验固定设置

- AVeriTeC dev 当前500题；以后模型/数据集分别建立新配置和run。记录数据/提示/配置/代码版本及模型服务身份；本地权重 revision、哈希、量化和 chat template 另留来源记录。服务模型ID不能证明权重永不变化。
- 三名同模型代理隔离初答 S0；“独立作答”表示不看同伴，不表示三个统计独立误差过程。
- 依据数据集、题号、seed=42 选发送者，冻结三份初答。统一四段 S0：Support A / Conclusion / Limitation / Support B，故结论首先限定于受控结构评论，不无条件推广到自然聊天。
- O加七种操纵：ethos/logos/pathos、conclusion_front/back、support_first/limitation_first。布局显式 group_first_v2。只改发送者评论，标签及其他人的初答不变。
- 同表达版本 I/M 共用 T1；随后 I 不收新同伴，M 每轮收另两人上一轮回复，两者固定到 T3，意见一致也不停。审计实际来源角色和源轮次与冻结 visibility-plan 是否一致。
- 一次主轨迹，每题8×2=16终局，每格三票。多个操作共用 O，三票/操作/轮次不作为额外独立题。三种不同标签记 no_majority，有金标时算不正确；运行缺失不是无多数。
- 每批10题，最多同时推进3题，题内串行。续跑自动恢复已记录的批次大小；新v2主矩阵未给参数时默认10。只有本批完整才进入下批；不把 skipped 当完整。

每题通常133次请求；500题通常66,500次，材料最多三次生成时任务上界72,500次，不含网络重试；总护栏90,000。人工核查和离线统计不额外调用模型。

上述批次齐全要求指默认严格执行。显式选择`--continue-on-error`时，旧有容错策略允许记下跳过并推进后续批次，最终必须报告completed_with_failures和缺失分母，不能将其称为8,000格齐全的正式完成。

## 操纵有效性

机械归一检查、模型语义审核与人工核查各承担不同职责：

1. 归一数字的千分位与无意义尾随零、规范域名大小写与常见尾随标点；保留路径大小写和百分比单位差别，检查 http(s)、www 和裸域名。它不证明数字在语境中的同义，也不覆盖所有事实变化。
2. 模型审核检查事实、推理、来源、限定条件、确定程度、操纵是否成立及连贯性。只有 pass 入组，fail/uncertain 不通过。新版本重排复验四段内容保持，处理文末换行。
3. 人工材料验证独立于后续回复编码：在模型输出前按 seed=20261022 预选50题，主矩阵最多350对 O/R。双人分别判断事实、推理、范围和不确定性保留，并对两文本的 ethos/logos/pathos 各给1–5分及逐字段原文引文。隐藏操作、模型、金标、结果；文本和原文/改写角色仍可暴露操纵，不能声称完全盲法。

先对真实三题试跑的21份材料做人工核查，确认提示能实现所定义操纵，再冻结正式配置。若需改变提示或资格规则，建立新版本和run，不把旧结果静默替换。全量预选50题的核查用于估计残余污染及操纵强度：报告每操作双人保留比例、uncertain、分歧与评分变化，不能用实体/数字对齐代替语义证据。

主自动流程的估计范围是通过自动资格门槛的材料。人审缺失不算通过；人审发现问题时公开污染与限制，不根据D/准确率选择删题。可预定报告“双人均确认保留”的敏感性子集，但它不能替换原始主结果，样本变化需另报。若无法支持内容保留，应收缩为“这些重写的影响”，不能继续声称纯表达因果效应。

完整矩阵要求所有七操作均合格才能讨论，这会限定可纳入题目。报告原始计划、S0缺失、每操作资格和全题资格，以及金标分布差异；不能隐藏失败题或宣称强行补齐材料后天然具有代表性。

长度记录不等于严格等长控制。本设计首先估计这些表达改写整体的影响，不能进一步声称修辞效应独立于字数变化。若要作此细分结论，须在新运行前增加长度匹配材料或独立复核；不靠结果出来后的协变量调整宣称所有内容与长度混淆都已消除。

## 推断与报告

- 每题先平均其可用完整重复（当前一次），题目是抽样单位；主D要求三轮四格完整。按题重采样整标签向量，bootstrap=1999、seed=20261022、alpha=.05。
- 中心化 bootstrap 的向量均值平方范数为整体检验；它不是处理随机化检验。主检验为T3 verdict的七操作整体向量检验。每标签95%区间为点态区间，不是同时区间。
- 零方差、单题、无完整题保留描述性估计，p和推断区间为NA，注明原因；不把经验点质量的零宽区间当成精确总体结论。
- 预定 Holm 家族保留不可估计槽位：计算时为这些槽位保守占位1，报告本身仍是NA。跨模型/数据集论文汇总时，必须对全部预定主运行重新计算论文级家族，不能用各run局部校正代替整体控制。工具：`tools/combine_study_inference.py`。
- 全量原始结果、配对分母、E轨迹、D及区间、家族大小、初态3:0/2:1/1:1:1分层、O→R和S0→终局变化、正确↔错误、无多数、资格与人审覆盖同时报告。S0后果采用完整臂的条件可用分母，与主配对分母区分。
- 分歧分层由处理前S0定义，保留全量主分析；不因为某层效应大就改成总体结论。如另行富集分歧题，须新建抽样设计并明确目标人群。
- 无显著差异只表示未获得相应证据。若没有事先给出有意义效应界限和相应等效分析，不宣称“没有影响”或“不会放大”。报告区间与能排除的效应范围；不按p值窥视决定追加样本/停止。

## 独立补充对照

补充条件使用自己的配置、冻结初态和run-id，不扩大主实验每题16格，也不复用旧I-T1轨迹。

| 对照 | 默认配置 | 作用与限制 |
| --- | --- | --- |
| 中性改写＋O/O | `averitec-rq1-neutral-oo-30-v2-template.json` | 预选30题；中性改写保持段落顺序，不刻意增强修辞；另两条O轨迹测同一冻结S0下的运行波动。不能覆盖全部S0/材料生成噪声，不扣噪声地板 |
| 定向消息屏蔽 | `averitec-rq3-message-30-v2-template.json` | 预选30题、示例固定logos操作，在T2屏蔽发送者S→A一条消息，其他历史保留；估计该路由干预后果，其他人仍可转述，不称纯中介效应 |

两份模板只作补充诊断，默认不输出主检验p。中性/O/O通常1,950次、计划上界2,070；消息对照通常1,410次、上界1,530。各调用护栏4,000。30题是成本默认值，不是功效保证；若论文核心效应很小，需在新运行前按所需精度固定更充分的对照样本。

中性改写是一般重写的参照，不预设其真实效应必须为零。若中性改写也影响判断，应照实报告，不能删除该对照以强化特定修辞解释。O/O给出条件于其冻结初态的描述性波动，不自动量化所有生成或服务漂移。

logos为固定预算示例，且既往探索结果已见过，不能包装成未接触数据的预注册选择。正式论文若要覆盖其他操作，先确定集合再plan和运行，不能事后只挑效果最大的操作。补充run的S0独立冻结，不能把它的单条轨迹与主run拼成相同起点的因果对照。

现有五轮RQ2只有M-O/M-R，可描述Eᴹ轨迹，不能计算T4/T5的I/M交互D；五轮提示/终局时点也不同。它是单独补充，不延长或代替三轮主对照。当前不加入ECE或主观Track2：没有正式置信度测量与人类分布数据，就不声称校准恶化或偏离人类分布。

## 人工回复编码

原V10要求50题全部回复，主矩阵将达到6,000条物理回复。本v2显式改为：仍预选50题，每题/模型最多12个自然逻辑回复单位，按轮次/分支分层、seed固定，在调用模型前把选定单位ID写入coding-plan，缺失不补选；最多600条、双人1,200份记录。它是抽样的探索性过程证据，不能声称覆盖每个传播路径。删掉 replies_per_item 可恢复所选题全部回复的模式，需承担其工作量。

五字段：立场保留、证据重评、表达复现、新论据、新事实；每字段yes/no/uncertain和逐字依据。O与共享T1物理回复不重复编码。报告覆盖、一致率、Cohen kappa和未解决分歧；评分与引用都由实际标注者完成，不从关键词自动造人工结论。具体命令和格式见[人工验证说明](human-validation.md)。

## 正式启动前的交付清单

1. 模型身份、能力、解码、数据与提示、预算、各样本计划冻结；新服务真实三题通过接口及16格验收。
2. 试跑材料由人工核查；明确这批核查是工程/操纵试点，不能混入正式统计以挑选更好结果。
3. 使用v2主配置启动；完成后检查500/500和8,000/8,000、消息路由审计、人工标注缺失与全体计划分母。
4. 在事先确定的小子集上执行中性/O/O及消息对照；明确其范围，不据结果调整主假设。
5. 公开模型/数据集选择及已有探索数据的影响；所有预定主运行进入论文级汇总。材料验证没做完就标未完成，数据不支持机制时收缩机制表述。

这一方案保证研究问题和读数有定义、遗漏可见、结果方向不预设；它不保证效应可检出，也不以某个会议录用结果作为方法验收标准。
